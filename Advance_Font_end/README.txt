BÀI THỰC HÀNH ADVANCE FRONT-END - RESPONSIVE & JQUERY

CẤU TRÚC
01-ecommerce: giao diện MIORA responsive, Bootstrap 3, xZoom, progress kho, giảm giá/nhãn, Bootstrap Star Rating.
02-jquery-lms: code chạy trực tiếp trong Console của trang LMS Moodle đã đăng nhập.
03-flappy-bird: game Flappy Sky, điều khiển Arrow Down, level theo điểm, chiến thắng ở 50 điểm.

CÁCH CHẠY
- Cài Visual Studio Code (nếu chưa có), mở thư mục Responsive_jQuery_Lab.
- Mở file index.html của từng thư mục bằng Chrome. Có thể dùng extension Live Server trong VS Code để chạy ổn định.
- Hai bài giao diện dùng CDN nên cần kết nối Internet.
- Riêng LMS: xem README trong 02-jquery-lms.
