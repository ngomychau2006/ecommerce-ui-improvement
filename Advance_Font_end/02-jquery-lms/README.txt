CÁCH CHẠY BÀI JQUERY LMS
1. Đăng nhập LMS UEH và mở trang môn học ở chế độ xem nội dung khóa học.
2. Nhấn F12 (Mac: Option + Command + I), chọn tab Console.
3. Mở file lms-console.js bằng VS Code/Notepad, copy toàn bộ và dán vào Console, nhấn Enter.
4. Xem nhóm kết quả “BÀI TẬP THỨ 5” và bảng “DANH SÁCH CHỦ ĐỀ”.
5. Chụp màn hình trang LMS và Console có kết quả thực tế.
Nếu Console chặn paste, đọc cảnh báo của Chrome và chỉ bật cho phép dán khi bạn hiểu rõ đoạn code đang chạy. Không dán mã lạ từ người khác.
Lưu ý: Moodle có nhiều giao diện; tên chủ đề/deadline có thể cần chỉnh selector theo HTML lớp thực tế.
